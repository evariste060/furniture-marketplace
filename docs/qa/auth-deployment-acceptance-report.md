**Changes made to the tests during the rebase:**
- **Database tests are PostgreSQL-only.** The SQLite fixture was replaced by the upstream per-schema pattern because the merged schema uses JSONB, regex CHECKs and triggers. They skip if `TEST_DATABASE_URL` is unset.
- **Real-HTTP harness hardening:**
  - The harness rebuilds `public` instead of `downgrade base`; the old approach broke when the test DB carried a removed revision.
  - Both harnesses force `MIGRATION_DATABASE_URL=""`, so a value in `backend/.env` can never redirect test migrations to the dev DB.
  - The audit-rollback test uses a non-keep-alive client. A shared keep-alive connection intermittently hit `WinError 10053` after the server closed it following an intentional 500. After the fix it passed 6 of 6 repeated runs plus the full suite.
